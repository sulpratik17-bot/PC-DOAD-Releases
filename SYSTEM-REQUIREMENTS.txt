PC DOAD 1.0.0
System Requirements
===================

Supported Platform
------------------
Windows x64

Release Type
------------
Self-contained Windows x64 application.

Installation
------------
The standard PC DOAD Windows installer requires administrator
privileges to install the application under:

C:\Program Files\PCDoctor

User Data
---------
PCDoctor stores user data under:

%LOCALAPPDATA%\PCDoctor

The installer does not intentionally remove this directory during
uninstallation.

Windows Release
---------------
Installer:
PC-DOAD-1.0.0-win-x64-Setup.exe

SHA-256:
46ED67BC642FD38700A333D37487DAC513694A2A6812C495D937D9D3DF02A775

Platform Verification
---------------------
The Windows x64 installer has been compiled, installed, and launched successfully. Uninstall and fresh reinstall were tested successfully. The app launched, and the user-data directory remained present. Exact record-by-record data integrity was not verified.

The Windows release has also been tested for background network-monitor
startup integration, Windows startup integration, uninstall behavior,
and preservation of PCDoctor user data.

Not Included
------------
Linux and macOS production builds are not part of this Windows release
package and have not been production-verified for this release.

Code Signing Notice
-------------------
This installer is unsigned. Windows SmartScreen or other security
controls may display a warning. Verify the published SHA-256 checksum
before running the installer.
