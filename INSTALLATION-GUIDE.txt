PC DOAD 1.0.0
Installation Guide
==================

Windows x64 Release

1. Requirements
----------------
This installer is for Windows x64 systems.

2. Installation
----------------
1. Run PC-DOAD-1.0.0-win-x64-Setup.exe.
2. Follow the installation wizard.
3. PC DOAD is installed under:

C:\Program Files\PCDoctor

4. A desktop shortcut can optionally be created.
5. PC DOAD can be launched at the end of installation.

3. Launching PCDoctor
---------------------
After installation, launch PC DOAD from:
- The Start Menu
- The desktop shortcut, if created
- The installed PCDoctor.exe

4. User Data
------------
PCDoctor user data is stored under:

%LOCALAPPDATA%\PCDoctor

The installer does not intentionally remove this directory during
uninstallation.

5. Uninstallation
-----------------
PC DOAD can be removed using the normal Windows uninstall process.

The Windows installer is designed to preserve the PCDoctor user-data directory
during uninstall.

6. Verification Performed
--------------------------
The current branding release has been verified for:
- Self-contained Windows x64 publishing
- Installer branding and preserved executable/install paths
- Existing user-data path preservation
- AppId preservation for upgrade/uninstall identity
